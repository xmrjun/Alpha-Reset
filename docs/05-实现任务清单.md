## 阶段 0：脚手架

**目标**：可运行的 TS 项目骨架

- `package.json`：ESM（`"type": "module"`），脚本 `test` / `dry-run` / `build`
- `tsconfig.json`：`strict: true`，target ES2022，module NodeNext
- 依赖：`better-sqlite3` `zod` `node-cron`；devDeps：`typescript` `@types/node`
- `src/types.ts`：**逐字照抄** `docs/04-架构设计.md` §4.1 的类型定义
- `src/config.ts`：读 `.env`（**机密**），zod 校验（缺 `ERWA_API_TOKEN` 直接退出并给出清晰提示）
- `src/config/strategy.ts`：读 `config/strategy.json`（**策略阈值，非机密**），zod 校验，忽略 `$comment` 键。
  类型见 `docs/04-架构设计.md` §4.3b。**校验失败直接抛错退出，不要用默认值兜底** —— 静默兜底会让人误以为跑的是 A 参数，实际跑的是 B

**验收**：`npx tsc --noEmit` 通过；`node -e "import('./src/config.js')"` 能正确报出缺失配置

## 阶段 1：指标层（纯函数）⭐ 重点

**目标**：`src/indicators/` 五个函数 + 完整测试

按 `docs/04-架构设计.md` §4.2 的签名实现：

| 文件 | 函数 | 要点 |
|---|---|---|
| `merge.ts` | `merge15mTo30m` | 按 30 分钟边界对齐；open 取首、close 取末、high/low 取极值、volume 求和；不足一对的尾部丢弃 |
| `rsi.ts` | `rsi` | **Wilder 平滑**（不是简单平均），period 默认 14，数据不足返回 `[]` |
| `sma.ts` | `sma` | 简单移动平均 |
| `breakout.ts` | `detectHigh` | `lookback=Infinity` 表示全部历史；返回创新高的 bar 索引或 null |
| `rps.ts` | `rps` | 排名赋分 `(1 - rank/total) × 100`；入参不含存续不足者 |

**必写的边界测试**（验收会逐条检查）：
- `merge15mTo30m`：奇数根、时间戳不对齐、空数组
- `rsi`：数据量 < period、全涨、全跌、含相等价格
- `detectHigh`：`lookback` 超过数据量、并列最高、空数组
- `rps`：单元素池、全部同涨幅（并列名次）、空 Map

**验收**：`npm test` 全绿；`grep -rE "fetch|Date\.now|sqlite" src/indicators/` **无输出**
